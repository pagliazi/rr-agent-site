# FAQ

**Q: 你们的 alpha 有多强？**
A: 策略 Top-N **回测** Sharpe 最高 4.51（回测口径，非实盘），均经 CPCV + DSR + 成本 gate 验证。**回测不代表实盘，实盘通常更低；我们不对任何收益作出承诺。** 详见[量化效果](performance.md)。

**Q: 会公开因子/策略吗？**
A: 不会。出于知识产权保护，仅展示类型与样本外效果，不公开名称、公式、参数与实现。公开的是**验证方法**（见[方法论](methodology.md)）。

**Q: 实盘曲线是真的吗？怎么保证不是回测？**
A: 真实账户。曲线用**真实持仓 × 真实每日收盘价**计算，可与账户记录交叉核对（我们内部已对账验证）。回测数据会**明确标注「回测」**，绝不冒充实盘。

**Q: 数据从哪来？准不准？**
A: ReachRich 多市场、多源数据平台，**多源交叉校验 + 除权复权一致 + 新鲜度监控**。详见[稳定性与准确性](https://reachrich.ai)。

**Q: 怎么防过拟合？**
A: CPCV 交叉验证 + DSR 多重检验校正 + 样本外回放 + 交易成本 gate。回测好看不算数，样本外扣成本后为正才算。

**Q: 系统稳定吗？**
