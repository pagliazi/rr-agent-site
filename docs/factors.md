# 因子库（匿名展示）

> 出于知识产权保护，**只公开类型与样本外口径，不公开名称、公式、参数与实现**。公开的是"我们如何验证"，而非因子本身。

## 七大类型

| 类型 | 直觉（非实现） |
|---|---|
| 动量 | 趋势延续 / 强者恒强的方向性 |
| 反转 | 超跌反弹 / 均值回归 |
| 价量波动 | 振幅、量价配合、波动结构 |
| 微结构 | 盘口、逐笔、日内交易行为 |
| 资金流 | 主力 / 大单 / 北向等资金行为 |
| 基本面 | 估值、盈利、财务质量 |
| ML 合成 | 多因子非线性合成（梯度提升等） |

## 入库门槛

候选因子须**逐项通过**方可进入实盘候选池：

1. **样本外（OOS）验证** —— 训练区间之外为正才算。
2. **DSR 多重检验校正** —— 扣除"试了很多次"的选择偏差，`p<0.05` 才认。
3. **交易成本 gate** —— 扣滑点 / 手续费后仍为正。

不达标进入观察 / 淘汰。详见[方法论](methodology.md)。
