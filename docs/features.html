功能

量化研究（RR-Agent）

  • 因子挖掘：LLM 辅助生成候选 + 严格样本外验证
  • 多类因子库：动量 / 反转 / 价量波动 / 微结构 / 资金流 / 基本面 / ML 合成
  • 机器学习选股：梯度提升模型 + 多重检验校正（DSR）
  • 组合优化：行业中性 + 风险约束的权重分配
  • 策略回测：CPCV 交叉验证，防过拟合
  • 风险归因：Barra 风格因子暴露分解

交易执行工具（RR-Agent · 用户自主）

供用户自主研究与执行的工具，非代客理财、非投资建议。

  • 自动执行 / 算法订单（VWAP / TWAP / 分批）
  • 实时风控：仓位 / 回撤 / 异动监控
  • 止损止盈 / 组合调仓
  • 多账户 / 多市场支持

RR-Agent（AI 协助 · 全链贯穿）

  • 多 provider LLM 可配置：支持配置 / 切换多家大模型提供商与模型，按任务自由选型，不绑定单一模型
  • RR-Agent 协助因子挖掘、选股、研究与决策
  • 自然语言交互，贯穿数据 → 因子 → 策略 → 执行全链
