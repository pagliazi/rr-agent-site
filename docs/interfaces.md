# 接口与交互

RR-Agent 提供三种使用方式，覆盖人机交互、脚本化与程序化集成。

## Web 控制台

模块化界面，常用模块包括：

| 模块 | 用途 |
|---|---|
| 概览 | 智能体状态、通道与运行时总览 |
| 行情 | A/港/美 行情，涨停、连板、板块、人气 |
| 量化 | 因子库、DSL 选股、健康分析、因子融合、策略库 |
| 盘中 | 盘中实时扫描与信号 |
| 资讯 | 新闻与 AI 摘要 |
| 回测 | 策略回测（CPCV） |

> 在线体验同款界面（演示数据）：[Demo](../demo/index.html)。

## 命令行

- `rragent` / `rr-agent`，适合脚本化与自动化流程。

## API / MCP

- **API**：程序化调用研究与数据能力。
- **MCP（Model Context Protocol）**：让大模型 / AI agent 直接驱动研究与取数；数据侧由 [ReachRich](https://reachrich.ai) 提供 MCP 数据能力。

```
人 ──▶ Web 控制台 / 命令行
程序 / 大模型 ──▶ API / MCP
                    │
                    ▼
              RR-Agent（研究全链）── 取数 ──▶ ReachRich
```

> 具体端点、鉴权与配置属产品配置，不在本展示仓库公开；不涉及主机、IP 或部署细节。
