🔌 MCP · Model Context Protocol for Quantitative Data

MCP 是 Anthropic 主推的开放标准(2024 年末发布),让 LLM(Claude/GPT/Qwen)直接发现并调用一组"工具"。本主题页汇总 MCP 在量化数据场景的应用与最佳实践。

什么是 MCP

传统接入数据:你写程序、按文档拼 URL、拿 JSON。 MCP 接入:LLM 在对话中自动调用 rr_quote(code='600519') 取实时报价;多工具组合("帮我看 600519 的 F10 + 资金流 + 同行业对比")LLM 自己分解、依次调用;用户讲自然语言不写代码。

MCP vs REST API:不是替代,是分层

层 接入方式 使用者
程序化 HTTP REST 生产策略 / 自动化
对话式 MCP 研究员 / LLM agent

ReachRich 同时提供两层 — HTTP API token 鉴权 + MCP 挂到 Claude/Cursor/Cline。

MCP 在量化场景的价值

  • 研究员探索:对话式取数,降低非程序员门槛
  • AI agent 工作流:多 MCP 工具组合(数据 + 可视化 + 交易)
  • 可重用工具链:写一次 MCP server,被所有 LLM 客户端调用

安全与限流

MCP 不解除任何鉴权/限流需求: - 每个 MCP 工具需要 token + 配额 - 敏感工具(交易、删数据)需要二次确认 - 审计每次 LLM 调用,防滥用
